# 楽譜エディタ

iPad のブラウザで使える、軽量な楽譜作成アプリ（PWA）です。MuseScore を参考にしています。
サーバーは使わず、楽譜はブラウザの中に保存されます。

## できること（ステップ1）

- 五線譜の表示（ト音・ヘ音・ハ音記号、ピアノ大譜表、調号、拍子）
- リピート記号（|: :|、回数指定）と1番・2番カッコ（再生もリピートをたどる）、弱起、曲の途中での調号・拍子の変更（「小節」メニュー →「リピート・途中の調や拍子・弱起…」）
- 音符・休符の入力、削除、音の高さの変更（ドラッグ／▲▼）、前後の入れ替え
- 音価（全〜16分、付点）、臨時記号（♯♭♮）、タイ、和音
- 元に戻す／やり直し
- ブラウザ内への自動保存、楽譜一覧、JSONファイルへの保存と読み込み
- PDF書き出し（A4、楽譜はベクター）
- ホーム画面に追加してオフラインでも使える

## できること（ステップ2）

- 画面下の鍵盤で入力（「🎹 鍵盤」で表示／非表示、◀▶でオクターブ移動）。黒鍵は調号に合わせて♯／♭を選ぶ
- 鍵を押さえたまま別の鍵を押すと和音。「和音」ボタンをオンにして1つずつ押しても和音
- 入力モードの「タイ」は、直前の音と同じ高さの音を足してタイでつなぐ（MuseScore と同じ）
- 再生（▶ 再生／■ 停止、スペースキー）。カーソルのある小節から鳴らし、⏮で先頭へ。再生中の音符と鍵盤が光る
- 音色は譜表ごとに「ピアノ」「電子音」（設定から）。音源ファイルを使わず Web Audio で合成
- 入力した音を確認音で鳴らす（🔊で切り替え）
- テンポ表記（♩ = 100）をタップしてテンポを変える。「♩= テンポ」ボタンで、カーソルのある小節からの途中のテンポ変更を入れる（再生に反映）
- チューニング（A4 = 440 Hz など）を設定で変える
- 入力位置が画面の外に出たら、自動でスクロールして追いかける
- ダブルタップで画面が拡大しない

## できること（ステップ4：楽譜の取り込み）

- ☰ ファイル →「PDF・MusicXMLを取り込む」で、次のファイルを開ける
  - **このアプリで書き出したPDF**：PDFに楽譜データを埋め込んであるので、元の楽譜にそのまま戻る
  - **MusicXML（.musicxml / .xml / .mxl）**：MuseScore などの楽譜ソフトや、読み取りソフト Audiveris の書き出し
- **ほかのPDF・写真・スキャン**は、パソコンの無料ソフト [Audiveris](https://github.com/Audiveris/audiveris/releases) で読み取って .mxl に書き出してから取り込む（手順はアプリ内の「ほかのPDF・写真の楽譜は？」）
- 取り込みの制限：1段につき2声部まで、ピアノなど2段のパートは段ごとに分ける、入れ子の連符や7連符などは近い長さに丸める、装飾音は省く
- 「MusicXMLに書き出す」で、ほかの楽譜ソフトへ持っていける

## 記号（スラー・強弱・奏法）

- **スラー**（キーボードでは S）：選んだ音符から次の音符へ。続けて押すと1音ずつ伸び、始まりの音符で押すと消える。
  入力モードでは直前に入れた音符とその前の音符をつなぎ、音を入れては押すと伸びていく
- **強弱**：pp〜ff・sfz・fp を選んだ音符に付ける。クレッシェンド／ディミヌエンドはスラーと同じように1音ずつ伸ばす
- **奏法**：スタッカート・アクセント・テヌート・マルカート・フェルマータ（休符にはフェルマータだけ）
- 再生にも簡単に反映：強弱で音量、クレッシェンドはだんだん大きく、アクセントは強く、スタッカートは半分の長さ、フェルマータは倍の長さ止まる
- PDF・MusicXML の書き出しと取り込みにも対応

## 画面の構成

- **上のバー**：☰ ファイル（楽譜一覧・新規・読み込み・書き出し）、曲名、再生（⏮ ▶ 🔊）、元に戻す／やり直し、⚙ 設定、PDF書き出し
- **下の道具バー**：左に入力方法（選択／入力／手書き、🎹 鍵盤）、右にパレット（音の長さ・付点・休符・タイ・和音・臨時記号・音符の編集・テンポ・小節）。
  手の届く下側にまとめ、幅が足りないときは横にスクロール
- **鍵盤**：道具バーの下。左右の ‹ › でオクターブ移動
- **表示の大きさ**：楽譜の右下の − 100% ＋（数字をタップで100%に戻す）
## 手書き入力

下の「手書き」（キーボードでは P）にすると、楽譜の上にペンで直接書けます。書き終えて少し待つと音符に変わります。
読み取りはiPadの中だけで動く図形の判定で、機械学習やネット接続は使いません。

| 書くもの | 読み取り結果 |
| --- | --- |
| 白丸 / 白丸＋縦棒 | 全音符 / 2分音符 |
| 黒丸＋縦棒（＋旗1本・2本） | 4分音符（8分・16分音符） |
| 黒丸だけ | パレットで選んでいる長さ |
| 音符の右に点 | 付点（あとから書き足しても可） |
| 音符の左に ♯ ♭ ♮ | 臨時記号（あとから書き足すと右の音符に付く） |
| 今ある音符の真上・真下に丸 | 和音 |
| 縦のギザギザ / 「7」/ 横の短い棒 | 4分休符 / 8分休符 / 全休符・2分休符 |
| 音符の上を横にこする、または × | 消す |

- 高さは音符の頭の位置で決まります。入力位置（青い帯）より右に書くと続けて入り、左に書くとその位置を書き換えます
- 2本指でスクロールできます。安価なペンは指と区別できないことが多いので、既定では指でも書けます。
  指で触って線が出てしまうときは「指で書く」をオフにすると、ペンだけで書き、指でスクロールできます
- 読み取れなかった線は赤く表示されて消えます。間違えたら「元に戻す」

## 使い方

| 操作 | iPad | キーボード |
| --- | --- | --- |
| 入力モード／選択モード／手書き | 下の「入力」「選択」「手書き」 | N / Esc / P |
| 音符を入れる | 入力モードで五線をタップ（ペンでも指でも可） | A〜G |
| 音の長さ | 全・2分・4分・8分・16分 | 7・6・5・4・3 |
| 付点 / 休符 / タイ | 付点・休符・タイ | . / 0 / T |
| 和音 | 鍵を押さえたまま別の鍵／「和音」をオンにしてタップ | Shift + A〜G |
| 再生／停止 | ▶ 再生 | スペース |
| 音を上下 | 選択モードで音符をドラッグ、または ▲▼ | ↑↓（Shift でオクターブ） |
| 削除 | 削除 | Delete |
| 元に戻す | ↶ ↷ | Ctrl/⌘ + Z / Y |

入力すると小節はいつも休符で埋まった状態に保たれ、小節に入りきらない音はタイで次の小節につながります（MuseScore と同じ考え方）。

## 開発

```sh
npm install
npm run dev     # http://localhost:5173 （同じWi-FiのiPadからも開けます）
npm test
npm run build   # dist/ に出力
```

`main` に push すると GitHub Actions が GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

## 構成

```
src/model/     楽譜データ（Score / Part / Measure / 音符）、音高・音価の計算
src/editor/    編集操作（入力・削除・移動・元に戻す）。画面以外の入力もここを通す
src/render/    VexFlow による描画と、タップ位置の当たり判定
src/storage/   ブラウザ内保存
src/audio/     再生（schedule: 楽譜→音の予定、synth: Web Audio の音源、player: 再生）
src/input/     画面の鍵盤
src/ui/        道具バーのアイコン（SVG）
src/export/    PDF書き出し（jsPDF + svg2pdf.js、必要なときだけ読み込む）、MusicXML書き出し
src/import/    取り込み（MusicXML / .mxl / このアプリのPDF）
```

今後の拡張の入り口は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) にまとめています。
